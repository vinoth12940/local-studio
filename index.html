Maximum context window
How many tokens the model holds at once: your messages, files, tool results and its reply. A larger window remembers more but uses more memory. The engine restarts with the new size on your next message; nothing is interrupted now.

About & updates

Local Studio and the engines it runs on

Uninstall

Stops everything, removes mlx-dspark, mflux and llama.cpp, the Mac app, and every model downloaded through Local Studio.

Prefer the terminal? Run ~/local-studio/uninstall.sh

Coding workflow

Plan inspects and updates planning artifacts. Act performs the selected task. Auto works within the task's scope and budgets. Edits and commands retain their approval requirements.

Task artifacts

Choose a workspace to create a task.

Scheduled tasks

Schedules and external calls only queue work. Nothing runs until you start it here, and every approval still applies.

Isolated workers

A worker edits its own Git checkout, never your workspace. You review the exact patch before anything is applied, and nothing is committed.
